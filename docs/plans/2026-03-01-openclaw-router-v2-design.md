**Date**: 2026-03-01

## 1. Problem Statement

The current openclaw-router is a TypeScript/Node.js project generated by OpenClaw that doesn't work reliably. It needs a complete rebuild with:
- Production-grade performance (sub-millisecond routing)
- Real-time model pricing and automatic switching
- A live dashboard at sunilkumarvalmiki.xyz
- Support for OpenClaw agents, coding tool proxying (Cursor/Claude Code), and general API gateway use

## 5. Core Features

### 5.1 Request Pipeline

1. **Auth** — Validate API key or JWT token
2. **Rate Limit** — Token-aware rate limiting per key (Redis token bucket)
3. **Format Translation** — Detect and normalize Anthropic/OpenAI formats
4. **Scoring** — 15-dimensional weighted analysis (<1ms)
5. **Classification** — Assign tier: SIMPLE / MEDIUM / COMPLEX / REASONING
6. **Cache Check** — Semantic cache lookup (cosine similarity > 0.85)
7. **Model Selection** — Pick optimal model based on tier + cost profile + availability
8. **Prompt Optimization** — Compress prompts, trim redundancies
9. **Provider Dispatch** — Send to selected provider with circuit breaker
10. **Response** — Stream back, log metrics, update cache

### 5.2 Scoring Dimensions (15)

1. Input token count estimate
2. Context length requirement
3. Code percentage (0.0–1.0)
4. Programming language count
5. Step count (multi-step reasoning)
6. Tool call count
7. Structured output requirement
8. Accuracy need (0.0–1.0)
9. Latency requirement (0.0–1.0)
10. Consistency criticality
11. Reasoning model needed (bool)
12. Vision support needed (bool)
13. Tool calling support needed (bool)
14. User tier (free/pro/enterprise)
15. Budget remaining

### 5.3 Cost Profiles

| Profile | Avg Cost/1M Tokens | Savings vs Premium | Use Case |
|---------|-------------------|-------------------|----------|
| ECO | ~$2.05 | 92% | Maximum savings |
| AUTO | ~$8.40 | 67% | Balanced (default) |
| PREMIUM | ~$25.00 | 0% | Best quality |
| FREE | $0.00 | 100% | Free-tier models only |

### 5.4 Provider Support (8 providers, 41+ models)

- **OpenAI** — GPT-4o, GPT-4 Turbo, GPT-3.5 Turbo, o1, o3
- **Google Gemini** — 2.5 Pro, 2.5 Flash, 1.5 Pro (1M context)
- **OpenRouter** — 300+ models, real-time pricing API
- **Ollama** — Local models (free), Qwen, Llama, Mistral
- **xAI** — Grok-4, Grok code-specialized
- **DeepSeek** — Chat, Reasoner
- **AWS Bedrock** — Claude, Llama, Mistral, Titan
- **Custom** — Any OpenAI-compatible endpoint

### 5.5 Cascade Routing

```
Request → Try cheapest capable model
            │
            ├─ Quality OK? → Return response
            │
            └─ Quality low? → Escalate to next tier model
                                │
                                ├─ Quality OK? → Return response
                                │
                                └─ Still low? → Use premium model
```

### 5.6 API Compatibility

| Endpoint | Format | Clients |
|----------|--------|---------|
| `/v1/chat/completions` | OpenAI | Cursor, Claude Code, Codex, any OpenAI SDK |
| `/v1/messages` | Anthropic | OpenClaw, Anthropic SDK |
| `/api/v1/route` | Native | Full control with scoring hints |
| `/health` | JSON | Load balancers, monitoring |
| `/metrics` | Prometheus | Grafana, alerting |

### 5.7 Semantic Caching

- Vector embeddings for query similarity (nomic-embed-text or similar)
- Cosine similarity threshold: 0.85 (configurable)
- Redis as vector store with TTL (1 hour default)
- LRU eviction at 10,000 entries
- Cache hit returns in <2ms vs 500ms+ for LLM call

### 5.8 Real-Time Pricing Sync

- Fetch OpenRouter `/api/v1/models` every 5 minutes for live pricing
- Fetch Google Gemini pricing API
- Update routing weights based on current prices
- Auto-switch models when rate limits detected (429 responses)

### 5.9 Circuit Breaker

- **Closed**: Normal, track failure rate
- **Open**: Provider down, skip for cooldown (30s default)
- **Half-Open**: Probe with single request to test recovery
- Per-provider independent circuit breakers
- Automatic fallback to next-best provider

## 9. Security

- API key auth for gateway, JWT for dashboard
- Token-aware rate limiting per key
- Input sanitization and length limits
- TLS everywhere (Let's Encrypt)
- Secrets in environment variables (never in code)
- CORS configuration
- SQL injection prevention (parameterized queries)
- Prompt injection detection heuristics

## 10. Cost Savings Display (INR)

Dashboard shows real-time conversion:
- USD → INR at live exchange rate (fetched daily)
- Default display currency: INR
- Toggle between INR, USD, EUR
- Savings calculated as: `(premium_cost - actual_cost) / premium_cost * 100`
